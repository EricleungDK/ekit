# mech-review/adapter-file: my own adapter file, written from the docs alone, makes R2 catch cheats in a brace language ekit does not know

- story: As a repo owner whose tests are in a language ekit has no built-in stack for, I write an adapter file from the CI docs' "Adapter file" section and run `r2 --stack <its name> --adapter <file>`: a deleted, skipped or weakened test fails, a changed expected value asks me to confirm, an unreasoned lint suppression and a mutation skip fail, an honest change passes.
- covers: #16 A1 (an adapter file describes everything R2 needs: test files by extension, test calls with groups and names, skip markers on a test and on a group, eq/ne/other asserts, a helper function shape, suppressions and their reason, a mutation skip marker, a manifest, the lexer table with block comments, escaped and multiline interpolated strings; the format in docs/mech-review-ci.md is enough to write it); A4 (an unbalanced test file, or an unterminated multiline string, is R2 `fail` class `needs-human`)
- steps:
  1. Copy `fixtures/ktspec.toml` (a Kotest-like `context("x", { test("y", { assertEquals(e, a) }) })` language, `.kt`, `//` and `/* */` comments, `"`, `'` and `"""..."""` strings with `${}`) and the `fixtures/base` repo (`build.gradle.kts`, `src/Calc.kt`, `tests/CalcTest.kt`) into the temp dir; commit base.
  2. Heads from base, each run with `mech-review.py r2 --stack ktspec --adapter ktspec.toml --test-paths 'tests/**'`: honest (adds `test("subs")`), `xtest("keeps")`, `xcontext("Calc")`, `keeps` deleted, `assertEquals(3, ...)` -> `assertEquals(4, ...)`, the `assertTrue` dropped, `// ktlint-disable-next-line max-line-length` without and with `-- why`, `// pitest off` in `src/Calc.kt`, a `)` dropped in a test, an unterminated `"""`.
- expected: honest and reasoned-lint exit 0 with no entries and summary `pass <head> (0 fail, 0 confirm; ran: R2; skipped: R1 R3 R4)`; the expected value exit 0 with one `confirm` `expected value changed in \`Calc / adds\`: was 3, now 4`; `xtest` exit 1 `test \`Calc / keeps\` disabled with an x prefix`; `xcontext` exit 1 with both tests named skipped; deleted exit 1 `test fn \`Calc / keeps\` removed`; dropped exit 1 `assertions in test \`Calc / keeps\` dropped from 2 to 1`; unreasoned lint exit 1 `` `ktlint-disable-next-line max-line-length` added without a reason ``; pitest exit 1 needs-human `mutation skip added: \`pitest off\``; unbalanced and unterminated exit 1, one `fail` `needs-human` `file does not parse`. No traceback; nothing written into the kit repo.
- children: malformed
