# Mech-review envelope

Per check, `<check> <status> <head sha>` copied from it. `skipped`/`n/a`/`partial` = not fully run: a ⚠️ row, with its note as debt. Quote `summary` only when every check ran in full; never write "all pass" yourself. Envelope `head` ≠ HEAD → stale: rerun mech-review at HEAD first.
